# PDF 전달 경로와 비개발자 안내

## 경로 선택

| 상황 | 권장 경로 | 이유 |
| --- | --- | --- |
| HTML을 받는 일반 사용자 | 브라우저에서 PDF 저장 | 개발 도구 설치 없이 인쇄 미리보기로 확인 가능 |
| AI에게 PDF까지 만들어 달라는 요청 | AI 실행 환경에서 변환·확인 | 사용자가 설치·명령 실행을 할 필요 없음 |
| 같은 문서를 자주 일괄 변환 | 선택적으로 로컬 자동화 | 초기 준비가 필요하지만 반복 작업을 줄일 수 있음 |

브라우저와 변환 엔진은 줄바꿈·글꼴·페이지 나눔이 다를 수 있다. 어느 쪽이든 최종 저장된 PDF를 기준으로 확인한다. 자동 변환 실패 시 사용자에게 설치를 떠넘기지 말고 브라우저 경로로 이어간다.

## 기본 안내: 설치 없이 브라우저로 저장

사용자에게 다음 내용을 상황에 맞게 짧게 안내한다.

1. HTML 파일을 다운로드한다. 다운로드 목록 또는 파일 탐색기/Finder에서 파일을 찾는다.
2. 파일을 Chrome·Edge·Safari 등의 인터넷 브라우저로 연다. 더블클릭해 코드 편집기가 열리면 파일을 오른쪽 클릭하고 ‘연결 프로그램’ 또는 ‘다음으로 열기’에서 브라우저를 선택한다. 인터넷에 공개할 필요는 없다.
3. 인쇄 창을 연다. Windows는 Ctrl+P, Mac은 Command+P를 누른다. 메뉴의 ‘인쇄’를 사용해도 된다.
4. 프린터 대신 ‘PDF로 저장’을 선택한다. macOS Safari에서는 인쇄 창의 PDF 메뉴에서 ‘PDF로 저장’을 선택한다. 실제 프린터가 필요하지 않다.
5. 용지는 A4, 방향은 세로, 배율은 100%, 한 장에 한 페이지로 설정한다. 머리글·바닥글을 끄고 여백은 기본값에서 시작한다. CSS의 페이지 여백과 인쇄 미리보기를 확인해 조정하고 이중으로 여백을 더하지 않는다. 배경색이 필요한 경우에만 배경 그래픽을 켠다. 브라우저별로 설정 이름과 위치가 다를 수 있다.
6. 미리보기의 모든 페이지를 살펴본 뒤 저장한다. 연락처·로고·제목이 잘리거나 빈 페이지가 생기면 무작정 배율을 낮추기보다 AI에게 HTML의 인쇄 배치를 수정하도록 요청한다.
7. 저장한 PDF를 다시 열어 확인한다. 원하면 PDF를 AI에게 첨부해 배치를 점검받는다.

모바일에서 파일 열기나 A4 설정이 어렵다면 컴퓨터에서 수행하는 방법을 우선 안내한다. 내장 미리보기가 실제 브라우저와 다르면 다운로드한 파일을 브라우저에서 열도록 안내한다.

- Chrome 인쇄: https://support.google.com/chrome/answer/1069693
- macOS PDF 저장: https://support.apple.com/guide/mac-help/save-a-document-as-a-pdf-mchlp1531/mac

## 선택 안내: AI 환경에서 자동 변환

- Python과 WeasyPrint가 이미 있으면 `python3 scripts/render_pdf.py INPUT.html OUTPUT.pdf`를 사용한다. 상대 경로는 스킬 폴더를 기준으로 해석한다.
- 변환 스크립트는 단일 HTML 안에 포함된 스타일과 data URI 자산만 사용한다. HTML이 참조하는 외부 URL·별도 로컬 파일은 읽지 않으며, 그런 참조가 있으면 PDF를 저장하지 않고 오류를 알린다. 승인된 이미지를 HTML에 포함한 뒤 다시 실행한다.
- `requirements.txt`는 Python 패키지 목록이다. WeasyPrint에는 시스템 렌더링 라이브러리와 한글 글꼴도 필요할 수 있다. pip 설치만으로 항상 해결된다고 약속하지 않는다.
- 허용된 AI 실행 환경에서 의존성을 준비할 수 있으면 직접 처리한다. PDF 전용 도구가 있으면 해당 절차를 따른다. 원래 HTML의 텍스트·이미지를 그대로 사용한다.
- PDF를 페이지별 이미지로 렌더링해 모두 확인한다. 글꼴·줄바꿈·페이지 수가 달라질 수 있으므로 브라우저 결과와 같다고 단정하지 않는다.

## 사용자 PC 설치를 정말 원하는 경우

- 먼저 브라우저 저장에는 설치가 필요 없다고 알려준다. 사용자에게 Python 설치를 기본 과제로 주지 않는다.
- 반복 자동화를 원할 때만 운영체제와 설치된 도구를 확인한다. 한 번에 질문을 많이 하지 않는다.
- 기술 지식이 없으면 한 단계씩: 어디를 열고, 무엇을 붙여넣고, 어떤 결과가 나오면 성공인지 설명한다. 명령만 나열하거나 운영체제를 추측하지 않는다.
- 현재 운영체제에 맞는 공식 설치 문서를 확인하고 최소 단계만 안내한다. 관리자 권한, 시스템 변경, 비용이 생기면 실제 필요한 범위를 설명한다.
- 오류가 나면 마지막 명령과 오류 메시지를 바탕으로 원인을 좁힌다. 같은 설치를 반복하지 말고, 복잡한 시스템 의존성 문제는 브라우저 저장으로 우회해 이력서 완성을 계속한다.
