# 이력서 작성

기존 이력서·경력 자료·지원 공고를 바탕으로 문제와 본인의 기여, 결과가 드러나는 HTML 이력서를 작성하는 Agent Skills 스킬입니다. ChatGPT·Claude 등 공통 스킬 형식을 지원하는 환경에서 사용할 수 있습니다.

## 터미널 없이 사용하기

개발 도구나 Python을 설치할 필요가 없습니다.

1. **[설치용 스킬 ZIP 다운로드](https://github.com/youngminnnn/resume-writing-skill/releases/latest/download/build-resume.zip)**를 눌러 파일 하나를 내려받습니다.
2. ChatGPT 사용자는 아래 상세 안내를 따릅니다. Claude의 사용자 스킬 업로드 화면에서는 이 ZIP을 선택합니다. 폴더 업로드를 요구하는 환경에서는 압축을 풀어 `build-resume` 폴더를 선택합니다. `SKILL.md`와 자산·참고 문서·스크립트를 함께 유지합니다.
3. 설치 후 “이 스킬로 내 이력서를 작성해줘”라고 요청하고, 기존 이력서나 경력을 정리한 자료를 제공합니다. 지원 공고는 있으면 함께 제공합니다. 자료가 없어도 짧은 질문으로 초안을 시작할 수 있습니다.

**설치용 ZIP과 저장소 전체 ZIP은 다릅니다.** 위 설치용 ZIP의 최상위 폴더는 `build-resume`이며 바로 안에 `SKILL.md`가 있습니다. GitHub의 **Code → Download ZIP** 및 Release의 **Source code (zip)**은 README까지 포함한 저장소 전체 소스입니다. 전체 소스를 받았다면 `skills/build-resume` 폴더만 따로 압축해야 합니다.

HTML을 받으면 다운로드한 파일을 Chrome·Edge·Safari로 열고 인쇄에서 **PDF로 저장 / A4 / 세로 / 배율 100% / 머리글·바닥글 해제**를 선택합니다. 모든 페이지를 확인한 뒤 저장합니다. PDF 생성에 Python 설치는 필요하지 않습니다.

### ChatGPT에서 사용하기

**앱에서 스킬을 설치하고 사용하기**

1. 위의 **설치용 스킬 ZIP 다운로드** 링크를 눌러 `build-resume.zip`을 저장합니다.
2. ChatGPT 데스크톱 앱에서 **Work**로 전환하고 컴퓨터의 파일을 사용할 수 있는 대화를 엽니다. Local/Cloud 선택 메뉴가 있으면 **Local**을 선택합니다.
3. ZIP을 첨부하고 아래와 같이 설치를 요청합니다.

> 첨부한 ZIP의 build-resume을 내 개인 스킬로 설치해줘. SKILL.md와 assets, references, scripts를 함께 유지하고, 설치가 끝나면 스킬 이름과 설치 위치를 알려줘.

4. 설치가 끝나면 앱 왼쪽의 **Skills**에서 `이력서 작성` 또는 `build-resume`을 확인합니다.
5. 새 대화 입력창에 `@`를 입력하고 해당 스킬을 선택합니다.
6. 기존 이력서나 경력 자료를 첨부하고 “이 스킬로 내 이력서를 작성해줘”라고 요청합니다.
7. 이어지는 질문에 답하고 초안을 확인한 뒤, 같은 대화에서 원하는 수정을 요청합니다.

**파일을 첨부해서 시작하기**

1. 위의 **설치용 스킬 ZIP 다운로드** 링크를 눌러 `build-resume.zip`을 저장합니다. 보통 컴퓨터의 **다운로드** 폴더에 있습니다.
2. ZIP을 압축 해제합니다. Windows에서는 오른쪽 클릭 → **모두 압축 풀기**, Mac에서는 ZIP을 더블클릭합니다.
3. `build-resume` 폴더를 열고 다음 세 파일을 찾습니다: `SKILL.md`, `assets` 폴더의 `resume-template.html`, `references` 폴더의 `pdf-workflow.md`.
4. ChatGPT에서 새 대화를 열고 입력창의 파일 첨부 버튼으로 세 파일을 첨부합니다. 파일 형식이 거부되면 해당 파일을 텍스트 편집기로 열어 내용을 복사해 대화에 붙여넣습니다.
5. 아래 문장을 보내고, 기존 이력서·경력 메모·지원 공고 중 가지고 있는 자료를 함께 첨부합니다.

> 첨부한 SKILL.md의 이력서 작성 절차와 HTML 템플릿을 적용해 내 이력서를 작성해줘. 먼저 내가 제공한 자료를 읽고, 부족한 사실만 짧게 질문해줘. 결과는 다운로드할 수 있는 HTML 파일로 제공하고 브라우저에서 PDF로 저장하는 방법도 알려줘.

새 대화에서 다시 시작할 때는 세 파일을 함께 첨부합니다. Python이나 터미널 설치는 필요하지 않습니다.

[스킬 사용 공식 안내](https://learn.chatgpt.com/docs/build-skills) · 안내 기준: 2026년 11월 11일

## 터미널을 사용하는 경우

Node.js를 사용할 수 있는 Claude Code·Codex 등 로컬 에이전트에서는 다음 명령으로 설치할 수 있습니다.

```sh
npx skills add youngminnnn/resume-writing-skill --skill build-resume
```

Claude Code만 선택하는 예:

```sh
npx skills add youngminnnn/resume-writing-skill --skill build-resume -a claude-code
```

Codex만 선택하는 예:

```sh
npx skills add youngminnnn/resume-writing-skill --skill build-resume -a codex
```

이 명령은 로컬 에이전트에 스킬을 설치합니다. ChatGPT 또는 Claude 웹 계정에 직접 설치하는 명령은 아닙니다. CLI의 Node.js 요구사항은 [설치 도구 문서](https://github.com/vercel-labs/skills)를 확인하세요.

## 설치 후 사용하기

### 1. 스킬을 선택하고 첫 요청 보내기

- **ChatGPT:** 스킬 등록 후 입력창에 `@`를 입력하고 `이력서 작성` 또는 `build-resume`을 선택합니다. 대화 첨부 방식으로 사용한다면 앞의 안내대로 지침·템플릿 파일을 첨부합니다.
- **Claude:** 스킬이 등록·활성화된 대화에서 “build-resume 스킬을 사용해서 이력서를 작성해줘”라고 요청합니다.
- **Claude Code:** 스킬을 설치한 프로젝트에서 대화를 열고 “build-resume 스킬을 사용해서 이력서를 작성해줘”라고 요청합니다. 자료의 파일 경로도 함께 알려줍니다.
- **Codex:** 스킬을 설치한 프로젝트에서 대화를 열고 `$build-resume`을 입력해 선택한 뒤 요청을 이어 씁니다. 자료의 파일 경로도 함께 알려줍니다.

스킬을 찾지 못하면 설치 위치와 현재 프로젝트를 확인합니다.

### 2. 내 상황에 맞는 요청 예시

**기존 이력서나 경력 자료가 있다면**

> build-resume 스킬로 첨부한 이력서와 업무 메모를 정리해줘. 먼저 자료를 읽고 부족한 사실만 질문해줘. 내 판단과 기여, 확인된 결과가 드러나게 작성하고 수치는 만들지 말아줘.

자료는 기존 이력서, 경력기술서, 포트폴리오, 업무 메모 중 있는 것만 제공하면 됩니다. 개인·회사 자료는 공유 가능한 범위에서 제공합니다.

**자료 없이 처음 작성한다면**

> build-resume 스킬로 이력서를 처음부터 작성해줘. 지원하려는 직무는 [직무]야. 최근 맡았던 일과 대표 경험부터 짧게 질문하고, 내 답변을 바탕으로 초안을 만들어줘.

**지원 공고에 맞춰 수정한다면**

> build-resume 스킬로 기존 이력서를 첨부한 공고에 맞춰 수정해줘. 실제 경험은 유지하고 관련 있는 경험의 순서와 설명 분량을 조정해줘. 공고에 있지만 내 자료에는 없는 역량을 추가하지 말아줘.

직무는 본인의 실제 지원 직무를 적습니다.

### 3. 질문에 답하고 초안 수정하기

담당 범위·판단·실행·결과에 관한 추가 질문에 답합니다. 회사 로고를 넣을지 묻는 경우 원하는 방식을 선택합니다. 이미 선호가 있다면 첫 요청에 “로고 없이 작성해줘” 또는 “공식 출처에서 회사 로고를 찾아 넣어줘”라고 덧붙여도 됩니다.

초안을 받은 뒤에는 같은 대화에서 구체적으로 수정해 달라고 요청합니다.

> 두 번째 경력의 해결 조치를 소주제별 bullet로 나눠줘. 개인 프로젝트는 문제/해결/결과 라벨을 반복하지 말고 자연스럽게 정리해줘.

> 소개를 두 문장으로 줄이고, 목표와 실제 성과를 구분해서 써줘.

### 4. HTML 다운로드와 PDF 저장

> 최종 이력서를 다운로드할 수 있는 단일 HTML 파일로 제공해줘. 모바일과 A4 인쇄를 고려하고, 브라우저에서 PDF로 저장하는 방법도 알려줘.

받은 HTML을 다운로드해 브라우저로 엽니다. **인쇄 → PDF로 저장 → A4·세로·배율 100%**를 선택하고 머리글·바닥글을 끕니다. 모든 페이지의 내용과 잘림을 확인한 뒤 저장합니다. Python은 필요하지 않습니다.

## 포함된 기능

- 기존 이력서·메모·공고를 먼저 읽고 부족한 사실만 질문
- 문제·본인의 판단과 실행·확인된 결과를 연결
- 여러 해결 조치는 소주제 bullet로 분리
- 회사 로고를 넣을지 확인한 뒤 사용자 이미지 또는 공식 출처 검색으로 추가
- 화면·모바일·A4 인쇄용 단일 HTML 템플릿
- 브라우저 PDF 저장 안내와 선택적 자동 변환 스크립트

성과나 수치는 제공된 사실을 바탕으로 작성합니다.

## 파일 구성

```text
skills/build-resume/
├── SKILL.md
├── assets/resume-template.html
├── assets/icon.svg
├── references/pdf-workflow.md
├── scripts/render_pdf.py
└── requirements.txt
```

업데이트할 때는 최신 ZIP을 다시 등록하거나 설치 도구의 업데이트 기능을 이용합니다.
